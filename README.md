# ArchForms — pitch

Presentación HTML interactiva: diapositiva 0 de espera y 30 diapositivas del pitch.

Sitio previsto: https://cdecasurpie.github.io/archforms-pitch/

## GitHub Pages

En **Settings → Pages**, selecciona:

- **Source:** Deploy from a branch.
- **Branch:** `main`.
- **Folder:** `/ (root)`.

Guarda y espera a que GitHub publique el sitio.

## Presentar

- Haz clic en la diapositiva, usa las flechas o espacio para avanzar.
- Los fragmentos se revelan antes de pasar a la siguiente diapositiva.
- Pulsa **P** o **Present** y permite ventanas emergentes para abrir la pantalla del público.
- El cronómetro comienza al salir de la diapo 0.
- Comparte la pestaña del público, no la ventana con las notas.
- PDF: [ArchForms-Pitch.pdf](ArchForms-Pitch.pdf).

Las notas del guion y los recursos del sitio son públicos. Las imágenes de la aplicación y los datos de ejemplo son ilustrativos. Procedencia de recursos: `deck/assets/third-party/SOURCES.md`.

Esta copia contiene solo los archivos de publicación, sin dependencias de desarrollo, cachés ni credenciales. La fuente editable se mantiene en el proyecto local `PPTHTML`.
